# 论文写作区

当前正文：[manuscript.md](manuscript.md)。这是一份基于已完成实验的中文研究初稿，不是完成全部实验的投稿版本。

独立维护的[参考文献列表](references.md)记录原始来源、结论与适用边界；[证据账本](evidence_ledger.md)将论断映射到实验和数据使用身份；[审稿评估](reviewer_assessment.md)记录相关工作覆盖与剩余缺口。进度仍只维护在[总计划](../docs/MASTER_PLAN.md)，本目录不另建竞争计划。

`results/` 与 `figures/` 是便于审阅的小型结果摘要，来源及哈希见 `results/provenance.json`。原始轨迹、特征、逐样本预测和完整归档保存在本地 `runs/`、`experiments/`，不随 Git 推送。摘要不能替代完整复现数据；正文明确区分代码核验、探索结果与独立确认。

`jepa_paper_draft.tex/.html/.pdf` 和仓库根同名文件是早期历史稿，保留不覆盖；其中“尚无表示比较结果”等状态已过时。当前工作稿以 Markdown 为准。

写作规则：每个主要数值有来源；每个既有方法有原始引用；推断与实验分开；不得将有标签读出、干预训练或两帧标定称为无监督发现；不得用正交交换恒等式证明因果独立；不得把已查看的开发集称为新确认集。
