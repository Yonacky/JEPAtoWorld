# 分离变换首批结果与下一步

2026-10-13；G-7f/g/h，沿用R2-2/I-4。三个Astra子智能体已完成有界构造实验，根任务核验103项清单（不是103次实验）。本轮不是只做探针诊断：实际学出了正交四块、可逆非正交分块和连续条件局部坐标三种变换。

## 结论

当前最值得继续的是良条件非正交分块。相同编辑目标、初值及200步预算下，它比正交变换更接近真实干预目标，同时提高最近邻目标识别。正交是更强结构约束；本批支持进一步检验是否需要放宽它，不证明正交方法一般无效。非正交具有更多自由度，不能说两族有效容量相同；保留cond≤2约束与同预算正交控制仍不足以代替独立确认。

## 两条未成功的构造

ANOVA主效应/交互正交四块把旧dev交互共享块捕获从3.59%提高至41.41%，但颜色目标恢复72.16%降至61.92%。主效应本就已有约94–95%集中于旧因素块。只把交互隔离后保留不动，不能正确更新与因素一起变化的交互；颜色真实变化含较大交互成分。这给下一步提供具体机制线索，而不是扩大正交搜索的理由。

连续局部chart颜色OOD误差1.398降至.818，但目标恢复.492降至.270；global6已取得.851，额外局部条件增益较小。局部矩阵秩6且cond≤4.63，不能归因于数值病态。真实双因素组合也未改善；循环和交换的代数性质通过不等于因素独立。保留这条有限失败，不扩带宽/维数。

## 核验与解释边界

非正交943488编辑在原5120维全量独立复算，最大场景指标差1.20e-12；正交四块目标下降、正交及全空间编辑检查通过；局部chart7776固定抽样独立重构通过。代码、拟合矩阵、源哈希、配置、所有候选、逐场景指标和报告保存在F盘，未推送。

三路线均使用训练干预信息，局部chart还用训练因素水平；这不是无监督发现。评估为真实干预表示及真值库检索，并未生成图像或执行控制。旧ID/OOD被反复查看，本轮不能称独立确认。数据尚是I-JEPA可独立操纵的视觉因素，不据此声明质量和外力可独立分离。

## 下一步顺序

先冻结非正交λ1、同目标正交λ1、原两参照joint0和noedit，生成新的ID/OOD场景，原模型不重拟合；按场景对检验编辑误差、目标识别与非目标保持，并补真实双因素组合。新批次应在生成前冻结种子/数量/统计主指标和停止规则。当前仅候选冻结建议，未生成新确认数据。

若新场景复现，再在相同视觉干预RGB上提取LeJEPA/V-JEPA适用输入并迁移构造。减少监督依赖与交互更新是后续独立机制问题，不把当前标签拟合包装成无监督DSReg替代品。需要无监督候选时，应利用观测响应/局部依赖或时序结构来约束分离，而非仅旋转高斯潜空间。
