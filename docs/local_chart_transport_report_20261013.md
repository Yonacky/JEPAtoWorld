# G-7h 连续条件局部线性chart与因素输运：探索结果

2026-10-13；R2-2 / I-4。执行与数值核验完成，未形成因素恢复成功或独立确认。CPU一次29.3秒；无GPU、无带宽/维数扫描。

本次新机制降低表示编辑误差，且连续条件相对同6维全局/同容量错配有小幅改善；但大部分收益来自6维加性坐标模型，颜色目标检索明显下降。OOD颜色误差虽首次在此候选上低于noedit，不能单据此称外推修复；OOD双因素目标恢复仍明显劣于旧两参照。因此保留为可组合局部坐标的有限正误差/负恢复证据，本轮停止扩参。

## 方法与证据身份

[冻结协议](local_chart_transport_protocol_20261013.md)与[独立原始文献登记](local_chart_transport_literature_20261013.md)。32个旧train场景，每场景27个真实干预图像、3因素×3水平；用Helmert对比定义6列共同坐标。训练使用因素水平，是明确增强监督。固定I-JEPA grid5120与旧PCA64。新场景仅两个固定参照000/222确定offset与128维条件描述子，用连续高斯核平均训练B_s，再用固定rcond=1e-8伪逆反解当前图像与donor坐标；真实目标codes不参与反解和编辑。

与旧L1–5不同，没有四中心硬gate，不用三个正交rank16块；每scene共享非正交6列chart和共同逆，先从donor反解目标两坐标，再在recipient chart解码其变化。与旧N2两参照单方向旋转也不同：多列坐标方向从训练干预统一。连续性仅关于场景条件；没有拟合逐物体状态的非线性切向场、黎曼度量或生成解码器，不称已发现流形。

旧tune8首先评价（4个独立scene pair），旧ID32/OOD32随后（各16pair）；所有集合此前已用过，本批都是探索。场景配对i/i+n/2双向、单因素432个conflicting edits，双因素216个（三因素中剩余factor冲突），scene/pair等权。nearest使用recipient的27真值表示作评价库，不输入生成编辑，不是图像生成或机器人执行。

## 图表拟合、交互残差与病态审计

32个训练scene的锚定6列chart拟合残差，相对场景中心化64维能量平均0.060212；三因素ANOVA主效应之外的交互残差份额平均0.044873。二者不同：前者受两个anchor固定原点与有限加性拟合约束，后者为不受anchor限制的主效应分解残差。不是全5120能量保留率，也不能把小总残差当颜色方向误差小。train逐scene/逐因素主效应能量、交互能量在fit.json；heldout诊断在results.json，未用于选模型。

所有测试global/local/wrong的有效秩为6，最坏条件数4.6291；最大伪逆谱范数1.01669（取决于固定PCA尺度），无条件数>1e4或截断秩失败。六个奇异值、forward/inverse范数、AB−I误差逐scene保存。因此此次恢复下降不能归因数值病态；更可能涉及加性6维模型、校准原点及目标度量取舍，但尚未作因果归因。

## 核验、产物与停止条件

生产计算用5120距离的低维展开；独立脚本用替代正规方程反解和直接5120编辑重算7776个固定样本（每scene/单或双目标/方法3个），delta最大差1.02e-14、相对误差差1.48e-12、最近参考距离差1.06e-11；训练chart系数另一线性解最大差3.11e-15。全部单编辑目标推进/能量比也重新归约。不是全部编辑逐个独立重算，也不是独立数据确认。
